## 📁 PACKAGE STRUCTURE

### 1. **model/** (6 classes)
   - Person.java - Abstract base class (Abstraction, Inheritance)
   - Student.java - Extends Person (Inheritance, Overriding)
   - Teacher.java - Extends Person (Polymorphism)
   - Course.java - Course entity (Encapsulation)
   - Marks.java - Grade calculation (Method Overloading)
   - Attendance.java - Attendance tracking (Exception Handling)

### 2. **interface/** (1 interface)
   - ReportGenerator.java - Report generation contract (Interface)

### 3. **repository/** (8 classes)
   - StudentRepository.java - Interface
   - InMemoryStudentRepository.java - Implementation
   - CourseRepository.java - Interface
   - InMemoryCourseRepository.java - Implementation
   - MarksRepository.java - Interface
   - InMemoryMarksRepository.java - Implementation
   - AttendanceRepository.java - Interface
   - InMemoryAttendanceRepository.java - Implementation
   
   **Concept**: Repository Pattern, Separation of Concerns

### 4. **service/** (4 classes)
   - StudentService.java - Student business logic (Method Overloading)
   - CourseService.java - Course business logic
   - MarksService.java - Marks business logic
   - AttendanceService.java - Attendance business logic
   
   **Concept**: Service Layer Pattern, Exception Handling

### 5. **gui/** (7 classes)
   - LoginFrame.java - Authentication GUI
   - DashboardFrame.java - Main dashboard with navigation
   - StudentPanel.java - Student CRUD interface
   - CoursePanel.java - Course CRUD interface
   - MarksPanel.java - Marks entry and calculation
   - AttendancePanel.java - Attendance tracking
   - ReportPanel.java - Report generation (Interface Implementation)
   
   **Concept**: Java Swing, Event Handling, Polymorphism

### 6. **util/** (1 class)
   - ValidationUtil.java - Reusable validation methods
   
   **Concept**: Code Reusability, DRY Principle

### 7. **data/** (1 class)
   - DemoData.java - Demo data initialization
   - Creates 5 students, 3 courses, 6 marks, 6 attendance records

### 8. **Main.java**
   - Entry point launching LoginFrame

## 💡 ARCHITECTURE DIAGRAM

```
┌─────────────────────────────────────────────┐
│         GUI Layer (Java Swing)              │
│  LoginFrame → DashboardFrame → Panels       │
└────────────────┬────────────────────────────┘
                 ↓
┌─────────────────────────────────────────────┐
│       Service Layer (Business Logic)        │
│  StudentService, CourseService, etc.        │
│  - Validation                               │
│  - Exception handling                       │
│  - Method overloading                       │
└────────────────┬────────────────────────────┘
                 ↓
┌─────────────────────────────────────────────┐
│    Repository Layer (Data Abstraction)      │
│  StudentRepository (Interface)              │
│  InMemoryStudentRepository (Implementation) │
└────────────────┬────────────────────────────┘
                 ↓
┌─────────────────────────────────────────────┐
│       Data Layer (In-Memory Storage)        │
│  ArrayList<Student>, ArrayList<Course>      │
└─────────────────────────────────────────────┘

Future: Replace InMemoryRepository with MongoRepository
        without changing GUI or Service layers!
```

## 🐛 COMMON ISSUES & SOLUTIONS

### Issue: "javac: command not found"
**Solution**: JDK not installed or not in PATH. Install JDK and add to PATH.

### Issue: "Main class not found"
**Solution**: Ensure compiled files are in current directory. Use `java Main` from src folder.

### Issue: "Classes cannot be resolved"
**Solution**: Compile all files together with correct package structure.

### Issue: GUI windows don't appear
**Solution**: Ensure SwingUtilities.invokeLater is used (already done in Main.java).
